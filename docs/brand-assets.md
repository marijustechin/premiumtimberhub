# Premium Timber Hub - Brand Assets

## Status

Working brand system for the MVP. It is intentionally flexible until a final logo and product-photography library are approved.

## Logo

- Current mark: simple `Premium Timber Hub` wordmark or existing approved SVG.
- Keep it easy to replace without changing page layouts.
- Do not represent the wordmark as a registered trademark unless that status is confirmed.

## Colour palette

| Role | Hex | Use |
|---|---|---|
| Primary | `#22412f` | Key interactive states and headings |
| Dark | `#16281d` | Footer and dark surfaces |
| Accent | `#c98a3b` | Restrained timber/warm-detail accent |
| Background | `#f6f2ea` | Warm light surface |
| Text | `#1c1917` | Main readable text |
| Base | `#ffffff` | Base surface |
| Border | `#e5dfd3` | Soft interface separation |

Maintain accessible contrast. Accent colour must not be the only indicator of state or meaning.

## Typography

- Headings: Fraunces, self-hosted WOFF2 where already available.
- Body: Inter, self-hosted WOFF2 where already available.
- If either font is removed, use an accessible system fallback and preserve hierarchy and legibility.

## Image direction

1. Prefer approved real photos of products, processing, packing, measurements and deliveries.
2. Use product close-ups and finished sauna/interior applications to explain a specific claim.
3. Stock or AI images may illustrate an application or design inspiration, but never appear as a Premium Timber Hub facility, shipment, finished project or customer installation.
4. Do not use jungle, exotic-tourism or container-logistics imagery as the dominant visual identity.
5. Optimise all web images to responsive WebP or AVIF. Keep high-resolution originals outside the public theme.
6. Use descriptive filenames and meaningful alt text.

## Required visual tone

Clean, European, technical-premium and restrained. Use light surfaces, dark green/graphite text, warm timber accents and generous whitespace. Avoid artificial filters that distort Natural or Thermo Abachi colour.
