# Premium Timber Hub - Design Principles

## Direction

Create a clean, technical-premium European B2B website for Abachi products. It should feel credible and specialised, not like a generic WordPress theme, tropical catalogue or consumer e-commerce store.

## Visual language

- Light, calm backgrounds; dark green/graphite typography; restrained warm-wood accents.
- Clear product hierarchy: Natural Abachi and Thermo Abachi before Raw Abachi.
- Generous whitespace, scannable technical content and direct enquiry actions.
- Product and process photography used as evidence, not decoration.
- No dominant maritime, container or jungle aesthetic.
- Subtle motion only; respect `prefers-reduced-motion`.

## UX rules

- Desktop navigation should remain concise; mobile navigation must keep the quote CTA reachable.
- Product cards follow a consistent hierarchy: name, format/application, one benefit, CTA.
- Technical details use responsive tables or card groups; never create unreadable horizontally clipped tables on mobile.
- Critical CTAs must work without animation or JavaScript-dependent interaction.
- Forms should communicate purpose, required data, success and error states plainly.

## Accessibility and performance

- One H1 per page, semantic heading hierarchy and descriptive link labels.
- Sufficient contrast, visible focus styles, keyboard operation and real form labels.
- Hero media is optimised for LCP; below-the-fold images are responsive and lazy-loaded.
- No autoplay video with sound.
- Avoid visual effects that distort product colour, especially Natural and Thermo Abachi.
